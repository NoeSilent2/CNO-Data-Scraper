# CNO-Data-Scraper
The python script I use it to convert raw Cobblemon data/resourcepack files into a reduced, organized database for the C&O Wiki.

Everything other than datascraper.py does not belong to me, and as such you may only get it from the original Minecraft datapacks, and also must abide by their licenses in its use.
We have permission to use all of this data for non-commercial purposes.
The content is used solely for populating the [C&O Wiki](https://cno-wiki.vercel.app/) and is here to aid in contributions to its database.
